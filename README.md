# 🔐 Interactive Login & Signup Form

A modern and responsive **authentication UI** built using HTML, CSS, and JavaScript. It includes client-side form validation with a clean and interactive design.

---

## 🚀 Features

- 🔑 Login & Signup forms  
- ✅ Real-time form validation  
- ❌ Error highlighting for invalid inputs  
- 🎨 Modern responsive UI  
- ⚡ Smooth transitions and interactions  
- 📱 Mobile-friendly layout  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

---

## 🧠 How It Works

- Uses JavaScript to validate form inputs  
- Prevents form submission when errors exist  
- Highlights incorrect fields dynamically  
- Checks for empty inputs and password matching  
- Responsive layout using Flexbox and media queries
